Escape from the castle!! (demo version)
---
This is a game where your main goal is to collect coins and escape froma castle. To do this, you would probably need some instruction below :>

How to play???? 
----
Now, you might be asking how can I play? WASD isn't working!! Well, for this game you need arrow keys. Only right and left!! Don't try to jump with up arrow key! 
If you want to jump, then use SPACE!! Literally...
